# 2026-10-10

## priceGYH —— 归一化股价 + 窗函数移动卷积平滑（research2026.py）
签名：`priceGYH(category='个股', name=None, window='exponential', T=5, start=None, end=None, table=None, show_progress=True)`
返回 `(dates, values, meta)`；`meta['normalized']` = 未平滑序列，`meta['members']` = 成分股（含市值权重）。

### 口径
- 归一化：以「分析起始时间之后第一个有数据的交易日」收盘价 = 100（即起始到上市之间为空 None，
  上市当日=100；中途停牌/缺数据也为 None）。起始默认 2001-01-01，结束默认当前时间。
- 行业：先按上证指数日历对齐逐股归一化，再**按市值加权**逐日合成（当日无数据的成分股不参与，
  权重逐日重新归一）；权重 = 总股本×市净率×每股净资产（亿元，基本面最近快照）。
- 平滑：`_smooth_series` 用 `causal_window(window, T)` 做因果单边加权移动平均（当前点权重=1，
  越远越小；窗内 None 剔除后重新归一权重）。8 种窗函数复用既有实现。
- 价格表默认 `self.price_table`（=后复权 dbbardata_bwd），可传 table 覆盖。

### 关键实现点/坑
- **交易日历**：用指数日线日期（`CALENDAR_CANDIDATES = 000001.SSE / 399001.SZSE`，覆盖 2001 起
  6229 个交易日）当日历，毫秒级；不要用 `SELECT DISTINCT datetime FROM dbbardata`（全表扫描几十秒）。
- **基本面名称/行业/市值取值必须用「最近 N 天窗口内每股最新一行」（`_recent_snapshot_map(days=60)`）**：
  jbmbaseA202607 是稀疏快照，**某股在最后一天不一定有记录**，用「最新一天」当基准会漏股票
  （现象：按名称查「平安银行」直接报未找到）。
- 名称/行业列没有索引 → 一律从最近窗口（约 20 万行）的内存字典里筛；只在都匹配不到时才全表兜底。
- 字段命名坑：`_price_members` 的返回 meta 里**不要用 "members" 键**（会覆盖 meta['members'] 成分股列表，
  现象：`TypeError: 'int' object is not subscriptable`）。
- 个股名称匹配支持：精确名称 → 模糊名称 → 6 位代码 / '000001.SZSE'（代码走主键索引，最快）。

## price_IndexBeiLi —— 股价(行业/个股)与基准指数的背离程度（research2026.py）
`price_IndexBeiLi(category, code, exchange, window, T, base_symbol='000985', base_exchange='SSE', start, end, mode='动量背离', table=None)`
→ `(dates, values, meta)`（多数值单位=百分点）。

- 标的：个股走 `_norm_price_series`（后复权+归一化+平滑）；行业复用 `priceGYH("行业", ...)`
  （市值加权）——注意 `priceGYH` 返回 `(dates, smoothed, meta)`，行业原始归一化序列在 `meta['normalized']`。
- **基准指数固定用不复权表 dbbardata**（`_resolve_base_index` 内 `table=self.bar_table`）：
  实测 **`dbbardata_bwd` 里个别指数被误复权**（000906.SSE 2015-01-05 变成 2344 点，原始 3944 点，
  比值 2.19x vs 1.30x），直接用 bwd 算基准会严重失真。指数点位本身不含分红、无需复权。
- 基准默认中证全指 000985.SSE（已停更 2016-06）→ 沿用候选链+覆盖度校验（45 天）自动降级，
  verbose 打印提示；实际落到中证800(000906)。
  **（2026-10-12 改为默认不替换，见本文件末节）**
- 背离程度两种口径（mode）：'动量背离' = 100×(标的 T 日涨跌幅 − 基准 T 日涨跌幅)；
  '相对强弱' = 100×(标的/基准 − 1)（相对分析起始点的累计超额收益）。
- 容错：代码/交易所支持 '000001' + 'SZSE'、'000001.SZSE'，甚至把全码误填到交易所位也可自动纠正；
  标的区间内无价格时明确报错（不再静默返回全 None）。
- 验证：平安银行 vs 中证800（2015-01-05 起）归一化终值 117.5 vs 130.0 → 相对强弱 -9.7%、
  动量背离 +5.1pt；行业「银行」42 家市值加权 +6.4pt；行业「白酒」vs 沪深300（2018-2022）正常；
  `price_IndexBeiLi("个股","000001")` 缺交易所 → 明确提示。

## 指数误复权修复（2026-10-10，runTDXchuquan/adjust_factor_builder/adjust_incremental）
- **根因**：gbbq 事件按 6 位代码匹配、**不带交易所** → SSE 指数(000xxx) 与深市同码股票撞车。
  实测：000985.SSE（中证全指）拿到大庆华科 22 个事件（fwd ×1.488、bwd 早期 ×0.67）；
  000001.SSE 拿到平安银行 27 个事件；**801 个指数类标的中 183 个被污染**（全部 SSE 000xxx）。
  同日内 OHLC 缩放一致，用户看到的「开盘价差异大」= fwd 整体 ×1.488、bwd 前后段台阶。
- **修复**：`adjust_factor_builder.is_index_symbol()`（SSE: 000/88/999, SZSE: 399, BSE: 899，
  已按 dbbardata 前缀分布核对）；`sync_adjusted` 与 `build_for_symbol` 对指数传空事件 → 恒等复制；
  运行 runTDXchuquan.py 时存量错误事件触发「事件变化」自动重建修复（selftest 的 000004.SSE 改成 600004.SSE）。
- **结果**：2129 个指数类标的不一致 0；真实股票（000001.SZSE）27 事件、0.5083 台阶不受影响。
- **教训**：全市场修复运行约 4 分钟会被 execute_command 超时杀掉 → 用 Start-Process 后台 + 轮询；
  跳过阶段零写入，中断安全。之前记忆「dbbardata_bwd 里个别指数被误复权」→ 已修复，但**指数点位
  仍应固定用不复权 dbbardata**（双保险）。

## 显示滤波（2026-10-10 补，viewPrice-IndexBeiLi）+ 通用 filter_series
- `research2026.filter_series(values, kind, length, param)`（模块级，配 `FILTER_KINDS`）：
  8 种：无滤波 / 移动平均(居中) / 移动平均(因果) / 指数移动平均(alpha=param 或 2/(L+1)) /
  中值滤波 / 高斯滤波(sigma=param 或 L/6) / 汉宁窗卷积 / 凯泽窗卷积。
  统一 NaN 语义（窗口内空值剔除并重新归一权重，全空则 None）；MA 用前缀和 O(n)；
  中值用 `sliding_window_view` + 左右补 NaN（`half_l=L//2, half_r=L-1-half_l`，窗口恰为 L）。
  已验证：长度不变、无 inf/nan、脉冲 300→中值 99（MA 只到 138）、常数序列保持常数、参数生效。
- GUI：新增「滤波方法/滤波长度(默认20)/参数(0=自动)」，作用于**函数返回结果**后再显示：
  单标的滤波背离序列 + 右轴归一化价格；批量滤波各曲线并在表格加「滤波后最新值」列（排名仍按未滤波值）。
- **改滤波设置不重算数据**：`self._payload` 缓存上次函数原始结果，滤波控件信号 → `render()`（`*_args` 吞掉信号参数）直接重绘。
- 注意：把 `valueChanged/currentIndexChanged` 直连无参槽函数时必须写成 `def render(self, *_args)`，否则 Qt 传参会 TypeError。

## 前20/后20 展示范围（2026-10-10 补，viewPrice-IndexBeiLi）
- `price_IndexBeiLi_batch` 新增 `bottom_n` 参数：`bottom_n<=0`（默认）= 老的「|最新背离值| 前 top_n」；
  `bottom_n>0` = **双端选取**（背离率最高的 top_n + 最低的 bottom_n），用两个堆（hi 用值、lo 用 -值）

  标题/状态栏显示范围（「显示前20+后20」/「显示|值|前12」）。

## 基准「不替换」（2026-10-12，price_IndexBeiLi / viewPrice-IndexBeiLi）
- 用户要求：**viewPrice-IndexBeiLi.py 基准默认中证全指，不允许自动替换成其他指数**（此前
  `_resolve_base_index` 覆盖度不足会沿候选链降到中证800，用户看到基准不是中证全指）。
- `_resolve_base_index(..., allow_fallback=False)`（默认）：**只用给定基准**——
  · 部分覆盖（末点距分析结束 > 45 天）：照用，verbose 只提示；
  · 区间内一个有效点都没有：抛 ValueError，并把**该指数在库中的可用区间**写进报文
    （新增 `_symbol_date_range()`：查 dbbaroverview 的 start/end，瞬间返回）。
  `allow_base_fallback=True` 才恢复原候选链降级；`price_IndexBeiLi` / `price_IndexBeiLi_batch`
  都透传该参数。
- GUI：新增复选框「基准覆盖不足时替换」（默认**不勾选**）；启动状态栏动态显示默认基准
