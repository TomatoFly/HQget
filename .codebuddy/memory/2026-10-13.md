# 2026-10-13：runUpdataTDX.py（按代码+交易所在线更新日线到当前时间）

## 功能与用法
- `python runUpdataTDX.py 000985.SSE`（也支持 `000985SSE` / `sh000985`、多标的、逗号分隔）：
  起始日自动 = 库内 `MAX(datetime)+1`（索引查询瞬时；库里没有则 1990-01-01 全历史），
  截止默认今天；经 `read_tdx_day_online`（pytdx；指数自动 get_index_bars / 个股 get_security_bars）
  拉数，写库与 runTDXQuanLiang 完全一致（convertToVNPYbarData + write_tdx_day 增量，幂等）。
- 库内末日期 ≥ 截止日 → 明确提示「已是最新，无需更新」并跳过（**不算失败**）；
  但**显式 `--start` 时不拦截**（允许回补/修复，重复日期由写库增量逻辑去重）。
- 更新完只写 dbbardata，结尾提示运行 `runTDXchuquan.py --symbol <代码>` 同步复权表。
