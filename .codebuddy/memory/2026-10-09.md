## 打包 GUI 为 exe（build_exe.py + PyInstaller）
- 环境：`C:\veighna_studio\python.exe` 原本没有 PyInstaller，已装 **pyinstaller 6.22.3**
  （用清华镜像 `-i https://pypi.tuna.tsinghua.edu.cn/simple`）。
- `build_exe.py`（项目内，可复用）打包两个入口：`viewGDHS.py`、`viewGDHS_Price.py`；
  默认 onedir + 保留控制台（能看扫描进度/异常），支持 `--onefile` / `--noconsole` / `--only` / `--clean-dist`。
  产物：`dist/<name>/<name>.exe`（每个目录约 424 MB，PySide6 占大头；build 缓存 146 MB）。
- **坑 1（致命）**：`--exclude-module unittest` 会让 exe 启动即崩：
  `pyparsing/testing.py` import unittest（matplotlib→pyparsing 间接依赖），
  报 `ModuleNotFoundError: No module named 'unittest'`。**排除列表里绝不能有 unittest**。
- **坑 2（更隐蔽）**：PyInstaller 若在 `--specpath` 发现**同名旧 spec 会直接复用**，
  导致本次改动的 `--exclude-module/--hidden-import` 静默不生效（现象：改了脚本重新打包，
  报错照旧）。**打包前必须删除 `<name>.spec`**（build_exe.py 已加自动删除）。
- 验证方式（不弹窗）：`$env:QT_QPA_PLATFORM='offscreen'` 后 Start-Process 跑 exe，
  等 60~105 秒，检查进程仍在 + stdout 有扫描进度 + stderr 无 Traceback。
  offscreen 下 stderr 会打 `QFontDatabase: Cannot find font directory .../PySide6/lib/fonts`
  与 `does not support propagateSizeHints()` —— **属正常噪音**，不是故障。
- 冻结后比解释器慢（首次全历史取数：解释器 ~55s，打包后 ~100s+，冷启动磁盘 IO 影响大）。
- 程序不依赖本目录资源（数据库路径写死在 research2026.py），exe 可拷贝到任意位置运行，
  但要求 `C:\Users\gdl_01\.vntrader\{fundamental.db,database.db}` 存在。
