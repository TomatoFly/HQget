# 2026-09-23（第二次）

## GDHS 变化率时间平移（pingyiGDHLHSAnlsy / getTableGDHSshift / getIndexGDHSshift）
- research2026.py 新增两个算子：
  - `_rate_series(values, T)`：周期 T 滚动变化率 rate[t] = v[t]/v[t-T] - 1；
  - `_shift_series(values, k)`：时间轴向后平移 k 期 out[t] = values[t-k]（不足为 None）。
- `pingyiGDHLHSAnlsy(T, kind, name, shift=None)`：返回二维数组 [[labels],[平移后变化率]]；
  kind 归一化 `_norm_kind`（个股/GG/stock→个股，行业/industry→行业）；shift 缺省 = T。
  行业分支用 GDHSindexV3(V1) 行业指数序列；个股分支用 numbleGDHSv1 **全历史**序列
  （曾误用 get_record 默认 16 期导致只有 17 点，已改为 periods=None）。
- `getTableGDHSshift(T, Tshift, kind)`：调用 getTableGDHShangye / getTableGDHSname，
  新增的 `shift` 参数把**变化率时间基点从最新期前移 Tshift 期**（`_window_change(offset=)`，
  前移后仍取有数据的点），表加「平移期数」列与「时间基点前移N期」备注，meta["shift"]。
- `getIndexGDHSshift(T, Tshift, method)`：指数序列→周期 T 滚动变化率→平移 Tshift；
  返回 (labels, shifted, meta)，meta['rates'] 为未平移序列。
- 验证：平移 k 期后 shifted[t]==rates[t-k]；行业表 shift=2 的第一名与 shift=0 不同（时基真实变化）。
