## 🐞 test1.py 输入框卡顿（很长一段时间繁忙、无法输入股票代码）✅
- **现象**：运行 `test1.py`，鼠标点进「代码」输入框后长时间繁忙，敲不进股票代码。
- **根因**：`matplotlib.widgets.TextBox._rendercursor`（每次**点击 / 输入一个字符**都会触发）在源码末尾执行 `fig.canvas.draw()`，即**完整重绘整张含数千根 K 线 + 成交量柱的大图**。在 QtAgg 后端下整图重绘极慢，表现为输入框卡死。
- **修复**：新增 `FastTextBox(TextBox)` 子类，重写 `_rendercursor`，把末尾的 `fig.canvas.draw()` 改为 `self.ax.redraw_in_frame()`（只重绘输入框所在 axes 的标签/文本/光标，不重绘主图）。`test1.py` 中 `text_box = TextBox(...)` → `text_box = FastTextBox(...)`。
- **验证**：Agg 后端最小脚本确认 `_keypress → _rendercursor → redraw_in_frame` 无异常；lint 0。真实效果需本机 `python test1.py`（QtAgg）交互确认流畅。
- **注意**：本机 GUI 唯一可用后端是 QtAgg；交互窗口须用 `python test1.py` 直接跑，**勿走 debugpy 调试器**（否则 Qt 事件循环与 debugpy 抢主线程，窗口标"未响应"）。
