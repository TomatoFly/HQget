### 关键口径坑（重要）
- **`jbmbaseA202607` 是「有变化才写入」的稀疏快照**（同一数值不重复写）。所以「季内取最后一条」会把「该季户数未变」误判成「该季缺数据」。
  对策：as-of 语义取数——`该季股东户数 = 截至该季季末(且<=当前时刻)最后一次有变化记录的值`，
  向前结转（carry-forward）。上市前 / 尚无数据的季度仍为 None。
- `fundamental.db` 当前数据截止 2026-07-24，今天 2026-09-10，所以「2026Q3」= 7/24 快照，
  是「未完整季度」，必须在备注中标注（不要补全）。
- 行情库**最新交易日**用 `dbbaroverview` 取（`SELECT MAX(end) WHERE interval='d'`），比扫 `dbbardata` 快几个数量级。
- 2010-9 起的 vnpy peewee 表对 dbbardata 等有索引 `(symbol, exchange, interval, datetime)`，但 dbbardata 上的 `SELECT MAX(datetime)` 没有索引 → 全表 2960 万行 ≈80s/次；用 dbbaroverview 替代。

### 类与 GUI
- `Research2026.numbleGDHSv1(end=None, window_months=3, periods=16, symbols=None, only_active=False, active_days=20)` → 返回 `(data, meta)`，data 是 list[dict]，含完整季度序列 + 环比变化率。
- `getTableGDHSname(periods=4, ...)` / `getTableGDHShangye(periods=4, ...)` → DataFrame + meta，**升序（减少最多在前）**。缺最近季度时按已有数据计算并 `数据缺省(实际/期望季度数)` 标注。
- `viewGDHS.py` 后台 `QThread + LoadWorker` 跑 `getTable*`（避免 UI 冻结 5~20s）；
  Research2026 连接用 `check_same_thread=False` 复用；
  `QTableWidget` 排序用 `NumItem(QTableWidgetItem)` 重写 `__lt__` 实现数值排序；
  右键 / 双击弹 `SeriesDialog` 用 `FigureCanvasQTAgg` 画两个子图（股东户数折线 + 变化率柱状）。

### GUI 环境
- 本环境 matplotlib GUI 后端仅 `QtAgg` 可用（PySide6 已装、PyQt6 没装、tkinter 没装）；
  matplotlib 会自动选 PySide6。
- 中文显示靠 `rcParams['font.sans-serif']` 设 Microsoft YaHei / SimHei 等等。
