# 2026-09-14

## 股东户数-价格背离率（GDHS_Price）
在 `research2026.py`（Research2026）与 `viewGDHS_Price.py` 上新增「股东户数 × 价格」背离率研究线。

### 语义约定（2026-09-14 最终版：价格权重**不**乘 -1）
- 背离率公式统一收敛在 `Research2026._div_of(w_gdhs, w_price, gd_rate, price_rate)`：
  **`div = w_price * price_rate - w_gdhs * gd_rate`**。
  正分 = 户数减少 + 股价上涨（筹码集中且上涨，看多）；负分 = 背离。
  （中间曾按用户要求把价格权重乘 -1，随后用户又要求撤销恢复；当前为不乘 -1 的版本，
  所有背离率计算点必须走 `_div_of`，禁止各处手写公式。）
- 价格表默认 `dbbardata_fwd`（前复权，锚定首日 → 区间涨跌跨期可比），自动探测、无则回退 dbbardata。
- **价格取数截止日默认对齐基本面数据最新日（align_cap=True）**：否则会出现
  「户数取 7/24、价格取 9/9」的错位比较（曾导致背离率 43.6% vs 27.7% 的差异）。
- 价格季度序列与户数同样 as-of 结转；表自动复用 numbleGDHSv1 的缓存；
  价格缓存按 (qmin,qmax,table,cap) 范围包含即可复用。

### 逐股取行情的性能方案（重要）
- `dbbardata(_fwd)` 只有复合索引 `(symbol,exchange,interval,datetime)`，任何只按 datetime 的
  条件都是全表扫描（2960万行 ≈几十秒）。
- `Research2026._load_price_quarters` 采用**逐股索引区间查询**（5000 只 × 每只一个
  `[qstart, cap]` 区间），5200 只全量约 4s，远快于单次全表扫描。

### 新增方法
- `numGd_price(w_gdhs=1.0, w_price=1.0, ..., align_cap=True)`：data 在 numbleGDHSv1 字段上
  增加 price_values/price_dates/price_rates/div_rates/latest_price。
- `getTableGDHSname_Price(periods, w_gdhs, w_price, ascending=False)`：默认背离率降序
  （分高在前）；列含「股东户数变化率%」（对应股票代码+时间周期插入）。
- `getTableGDHS_pricehangye(periods, ...)`：行业背离率 = w_price*成分股价变率中位数
  - w_gdhs*户数合计变化率（配对样本）；series 含行业等权价格指数（各成员相对自身首个有效价）。
- 个股 series 新增 `div_window`（滚动 periods 窗背离率，GUI 主图用它）、`gd_window`、`price_window`。
- `viewGDHS_Price.py`：权重 QDoubleSpinBox ×2、排序方向下拉；绘图 3 子图
  （户数 / 价格(或行业等权指数%) / 背离率柱）；行业表列含「股东户数变化率%」。

## 全历史序列（2026-09-14 补，用户反馈双击只显示 2025-2026）
- 原因：getTable* 内部只加载 `periods+2` 个季度，series 自然只有一年半。
- 修法：`numbleGDHSv1(periods=None)` = **全部可得历史**（按 `MIN(datetime)` 自动算期数，
  数据 2016-08 起 → 41 个季度）；`numGd_price(periods=None)` 默认全历史；
  `_ensure_data` 与 `getTableGDHSname_Price/getTableGDHS_pricehangye` 都改为加载全历史。
  表格的窗口计算仍锚定最新索引（i_now - periods*step），结果与之前完全一致，已验证。
- 成本：全历史首载 ≈ 55~85s（基本面 884 万行扫描 ~32s + 逐股价格 ~20s），之后全部走缓存。
- GUI：标题改两行（主标题+备注，fontsize=9）；viewGDHS 户数逐点标注加 `len(pts)<=24` 保护；
  绘图备注注明「序列=全部可得历史(N季)」。

## 价格源改为后复权 dbbardata_bwd（2026-09-14 用户要求）
- `Research2026._pick_price_table` 优先级改为：**dbbardata_bwd → dbbardata_fwd → dbbardata**。
- 注意：本项目 fwd/bwd 是同一套单事件因子的两种锚定（fwd 锚定首日 h、bwd 锚定最新 q，q=∏_{ed>t}f），
  **两列的区间涨跌幅（比值）完全相同**——切换只改变价格绝对水平（bwd 最新价=不复权价，
  历史价往下调；本口径与标准"后复权历史放大"相反，是用户自定义口径），背离率数值基本不变。
- GUI 绘图纵轴标签改「收盘价(后复权)」。价格缓存 key 含表名，切换表自动失效重取。
- 已重新计算+绘图验证：000001 平安银行 全历史 41 季，近 4 季度 背离率 0.05%（户数+3.16%、价+3.21%）。
